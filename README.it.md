# lumen-website

Italiano | [English](README.md)

Il sito web del progetto [Lumen](https://github.com/lumen-assistive): il
pitch, lo stato dei moduli, la sintesi sulla privacy, il rimando all'SDK e
lo stato del download. Costruito con [Astro](https://astro.build) e
distribuito su Vercel.

Questa repository contiene il codice del sito, non la documentazione
tecnica di Lumen. La documentazione tecnica dell'SDK e del motore dei
sensi vive nelle rispettive repository
([lumen-sdk](https://github.com/lumen-assistive/lumen-sdk),
[lumen-core](https://github.com/lumen-assistive/lumen-core)) e viene solo
collegata da qui, mai duplicata.

## Politica sui contenuti

Questo sito non pubblica mai test utente, metriche o partnership
inventate. Le sezioni senza contenuti reali lo dichiarano apertamente
invece di essere riempite con numeri segnaposto o testimonianze inventate.

## Sviluppo

```
npm install
npm run dev
npm run build
```

Installa l'hook condiviso per i messaggi di commit prima di fare commit:

```
git config core.hooksPath .githooks
```

Vedi [CONTRIBUTING.md](CONTRIBUTING.md) per il flusso di lavoro completo
(in inglese, come tutto il codice e la documentazione tecnica del
progetto).
