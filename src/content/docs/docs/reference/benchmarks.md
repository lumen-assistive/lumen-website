No model has been converted or benchmarked yet, so there is nothing to report here. This page exists now,
intentionally empty, so that the commitment to publish real benchmarks, and never fabricated ones, is
visible from the start.

Once a model exists, the table is generated by the
[`lumen-models` benchmark harness](/docs/models/benchmark-harness/) run against real target hardware. It
is not hand edited.

## What will be reported

| Column | Source |
|---|---|
| Mean and p95 latency | Wall clock timing of repeated inference calls |
| Peak memory | Traced memory of the benchmark process |
| Battery drain | Measured separately with platform tooling and supplied to the harness, never estimated |

## Rules

- Numbers come from real runs on named hardware. A development machine result is not a phone result.
- Battery drain requires on-device instrumentation (Android Battery Historian, iOS Instruments).
- The model must already have a cleared license in the [ledger](/docs/models/license-ledger/).
